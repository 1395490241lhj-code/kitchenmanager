# 归档规则

`docs/archive/` 保存已经结束、仍有审计价值且不再维护的阶段证据，例如最终验证、迁移记录、发布演练结果和 closeout audit。

归档文件：

- 记录当时基线、范围、命令、结果和限制；
- 视为不可变证据，除路径修复或明确勘误外不继续改写；
- 不得继续描述当前项目状态、当前 blocker 或下一步；
- 不得作为 Agent 默认阅读材料；活动文档只链接必要的最终证据。

可由代码或数据重新生成的报告进入 `artifacts/`、`reports/generated/` 或临时目录，默认不提交。单次任务、分支进度和临时调查留在 PR/Issue。

归档前必须确认该文件已被权威文档替代、没有活动引用、没有开放 PR 冲突，并更新所有入口链接。不确定的候选只列入治理报告，不移动。
